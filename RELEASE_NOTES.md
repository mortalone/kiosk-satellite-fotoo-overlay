## Screensaver Overlay Suite 0.11.8

Quick Actions & Clock 0.2.8 is now available directly through Kiosk's GitHub updater:
https://github.com/mortalone/kiosk-satellite-quick-actions

Use Display & clock settings (saved) in plugin Actions to configure dashboard
quickactions and independent clock/date display. Choices persist across restarts.
The normal manifest remains within Kiosk's 20-setting limit while retaining
battery icons/color, ordering and per-item entity/time rules from the separate repo.
The 0.11.7 Quick Actions ZIP exceeded the setting limit; use 0.2.8 instead.
Party actions are hidden by default and its existing opt-in still works.
The plugin clock is always hidden in Party Mode.

Wall Art/Fotoo launch/attach commands and the ready-made HA scripts remain included.
Nature Frame 0.8.2 retains the signed private gallery cover fix.

The dedicated repo is the update source for Quick Actions. Suite ZIPs remain
available, including the unchanged compatibility, doorbell, Now Playing and
spectrum plugins. CI validates host manifest budgets, visibility rules, battery
levels and Android compilation/D8 packaging.
